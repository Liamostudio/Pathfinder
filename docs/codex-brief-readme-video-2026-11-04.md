Restructure `README.md` with these sections, keeping what is already correct and cutting what is stale:
1. **What Pathfinder is** (3 sentences): a safety layer that lets a robot arm work around people. Meta's models see, understand and decide; a small, checkable local layer enforces; models never drive the motors.
2. **What it does, as built** (honest table: feature, state, evidence): hand gate (MediaPipe, two fused cameras, 150 ms watchdog, latched stop), SAM 3.1 people and hands into a voxel map (SAM is too slow to be the safety path), manual no-go cubes enforced as hard rules and routed around, Muse Voice Transcribe + Muse Spark orchestrator with five constrained tools through Meta glasses and an iPhone app, motion behaviours (waits for a hand, recovers from faults, cancel and carry on), workspace scan (MapAnything + SAM 3.1) with a voxel editor.
