## Track B: Claude (this session)

1. **Housekeeping (15 min):** move the MediaPipe environment and hand model out of `/tmp` into a persistent `~/src/hands-venv`; record the extras in `pyproject.toml` (`vision`, `hands`, `sim`, `models`; torch stays out of core). Test: hand detector runs from the persistent env.
2. **B1 Live hand test (20 min, needs L):** run the MediaPipe detector on the live Ace Pro feed through the watchdog, with lens calibration applied. Measure detection rate and latency with a moving hand, an occluded hand, and a hand over the table. Result goes into `PROGRESS.md`; this replaces the static-hand benchmark. Cut line if it is poor: tune thresholds, do not change the architecture.
3. **B2 Model layer (90 min), `lookandpick/models/`:**
   - `MetaClient`: OpenAI-compatible chat with tools, stdlib HTTP only, retries, a hard spend and call-count guard read from `.env`, no network in the safety path.
   - Call log: every model call by name with input, output, latency and token cost, in the format Deck's timeline already shows.
   - `Orchestrator`: Muse Spark gets `get_scene()`, `pick(id)`, `place(id, loc)`, `stop()`, `say(text)` as tool schemas and calls the real `Tools`. It is not allowed anything else: arguments are validated, ids must exist, `stop` is handled locally and bypasses the model.
   - `FakeLLM` that replays scripted tool calls, so tests are deterministic and cost nothing.
   - Tests: against a local fake HTTP server (retries, bad JSON, refusal, spend cap hit) and the scripted FakeLLM driving the sim. Then one real call (a cent) once the key exists.
4. **B3 Voice (45 min):** `VoiceTranscriber` with the file-upload endpoint first (simple, testable on a WAV), then the realtime WebSocket with push-to-talk mic capture. Fake transcriber for tests. Confirm the WebSocket key placement from the docs page. Test: a recorded sentence becomes the right command text.
5. **B4 Language to target (2 hours):** a SAM worker in the SAM scratch environment (Python 3.14, torch cu130) exposing localhost HTTP: frame and text prompt in, masks and scores out. The app side is a `SamTracker` (implements `Tracker`): runs on object events, not on a timer; mask centroid to table position through the calibration with the object's height; two cameras associated by position when the second is present; ids stable across frames. Develop against sim frames (needs X's textured props) and the live Ace Pro. Test: "the left one" picks correctly between two mugs in sim; mask-to-table error against sim ground truth under 1 cm at 1280x720. Cut line, in order: second camera, target confirmation.
6. **B5 Integration harness (90 min, evening):** `lookandpick/runtime.py` composes Tracker (SAM or fake), Arm (sim client), hand loop, orchestrator and the voice input, and starts Deck with the sim as its backend. Add an end-to-end scenario "pick up the mug" (text first, voice second) to the sim scenario runner, run 10/10, and include a model outage and a hand crossing mid-pick. Everything labelled in the timeline.
7. **Close-out (20 min):** `PROGRESS.md` updated (what passed, how it was tested, what did not), commit, push.
