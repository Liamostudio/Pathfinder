# Code audit — 27 October 2026

Scope: all project Python modules, adapter contracts, tests, SAM scripts and setup docs,
including the calibration work that landed during this audit. No motors were powered.

The project is a simulation scaffold plus standalone perception experiments. The separation
between model tools, world state and adapters is useful. The safety code is still a prototype;
these fixes do not establish safe operation of the real arm.

## Fixed

| Issue reproduced | Change |
| --- | --- |
| NaN hand coordinates produced a NaN speed; infinite coordinates could permit full speed. Invalid goals also reached the motion gate. | Reject malformed/non-finite coordinates and non-finite separation values. |
| A tracker returning fresh object instances lost grasp state, so place failed after a successful pick. Held objects also disappeared when occluded. | World state copies detections and preserves controller-owned grasp state, including during occlusion; held positions follow the arm. |
| Pick/place reported success even if the final retreat was blocked. | Report the partial outcome and preserve whether the object is held or released. |
| Arm refusal and gripper failure were treated as success. Gripping bypassed the safety gate. | Require explicit completed-action results from both adapter methods and gate gripping too. |
| Concurrent pick/place calls could interleave. | Reject a second action while one is running; stop never waits on that action lock. |
| An explicitly empty fake scene produced default objects. | Distinguish an empty list from omitted input. |
| Camera failures silently ended capture; writer failures could produce a misleading saved message. | Raise explicit errors, finalise recordings on exceptions/interrupts, and check frame counts, timestamps and dimensions. Preserve existing recordings. |
| SAM smoke output still read object IDs at the wrong dictionary level; its steady FPS numerator assumed a fixed clip length. | Read nested outputs and count actual measured intervals. |
| SAM preview leaked temporary frames on normal GUI quit and exceptions, and crashed obscurely on empty clips/missing weights. | Clean up capture, sessions, writers, windows and scratch frames; validate inputs; expose checkpoint/video options and clear CUDA errors. |
| Calibration accepted negative marker sizes and returned NaNs for invalid pixels. Calibration input arrays could be mutated externally. | Validate finite geometry, positive marker size and basic intrinsics; copy calibration arrays. |
| Calibration tests imported optional numpy before checking whether it was installed. | Skip vision tests cleanly when optional dependencies are absent. |

The adapter contract changed: `move_to` and `grip` now return `True` only on completion,
`False` on refusal/interruption. An acknowledgement that a command was merely queued is
insufficient. `None` fails closed. Only `SimArm` is implemented at present.

## Remaining priorities

1. **Before connecting a real arm: continuous fail-closed monitoring.** `allowed_speed([])`
   currently means full speed; there is no distinction between a verified clear scene and
   missing/stale/failed hand detection. Add observation timestamps, a detector health flag,
   a local watchdog and tests for camera loss, frozen frames, delayed results and exceptions.
   Monitor throughout motion, not just at tool boundaries. Test worst-case stop latency.
2. **Interruptible hardware controller.** The adapter must enforce the stop latch itself,
   including a stop racing with dispatch, and interrupt ongoing motion. Exceptions must
   halt/latch safely. Validate completion, gripper state and explicit local rearming. The
   simulated concurrency test does not prove any hardware behaviour.
3. **Calibrated geometry and limits.** The current distance check uses a hand point versus
   a straight end-effector segment; it does not cover robot links, gripper width, carried
   objects or a planned curved trajectory. Add workspace/joint limits and appropriate swept
   geometry. The 15 cm / 50 cm constants are placeholders, not validated stopping distances.
4. **Real calibration acceptance.** Measure camera intrinsics/lens distortion, printed marker
   size and marker-to-arm transform. Reject poor reprojection fits, camera movement and
   implausible poses. Validate independent table points across the whole reachable area.
   Synthetic tests are useful evidence but do not pass the physical milestone. The `z`
   argument assumes known object height; it does not estimate depth.
5. **Connect perception to one simulated task.** Convert detections into stable object IDs
   and calibrated coordinates, then drive a simulated pick. Add the lightweight hand detector
   independently of SAM. SAM remains record/process/replay, with no throughput improvement
   established here. Keep scene reads responsive while perception is busy.
6. **Reproducible SAM setup.** The scratch environment, upstream checkout and checkpoint
   are outside the repo. Record the upstream commit and tested dependency versions in a
   dedicated setup guide before packaging the demo; do not add an unpinned torch install to
   the minimal core dependencies. Test the changed scripts on the GPU before relying on them.

No new physical milestone was ticked. Changes are local and were not pushed by this audit.
