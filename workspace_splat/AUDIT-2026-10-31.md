# Workspace splat audit — 31 October 2026

Scope: image/video ingestion, GUI job management, local reconstruction/training/export,
hosted Meta SAM 3D integration, WebGL viewer and simulator iframe integration. This
is a code and regression audit; it does not certify reconstruction quality or robot safety.

## Provider recommendation

Use **fal.ai**, model `fal-ai/sam-3/3d-objects`. Its [published model page](https://fal.ai/models/fal-ai/sam-3/3d-objects)
lists **$0.02 per generation** today. The [documented API](https://fal.ai/models/fal-ai/sam-3/3d-objects/api)
accepts an image and object prompt and returns a Gaussian PLY that this importer supports.
Use a fal key/account; Meta Model API credentials and credits do not apply.

This recommendation is for single-image object prediction. The local COLMAP/gsplat
backend remains the appropriate implemented path for fitting a workspace from overlapping
views. Four sparse photos still leave unseen surfaces, holes and floaters.

The official Stripe Directory CLI/plugin was attempted as required by the provider-discovery
workflow, but its service rejected the lookup with “Invalid user agent”. Provider capability
and price were therefore checked against fal's official documentation. No account was
created or provisioned and no purchase or paid inference was performed.

## Findings fixed

| Priority | Bug and effect | Fix and verification |
| --- | --- | --- |
| P1 | An original filename could equal a different image's normalised ID, sending the wrong selected image to fal. | Resolve normalised IDs first, source names second; regression confirms the exact selected file and its colour. |
| P1 | Concurrent uploads could both pass the duplicate/budget checks, overwrite the same temporary file or race worker launch. | Serialise upload checks/writes and launch under one re-entrant lock; concurrent duplicate test permits exactly one winner. |
| P2 | After a server restart, a detached worker appeared active but could not be cancelled; another capture could also be launched. | Recover and verify the process owner, command/module, capture argument, process group and non-zombie state. Reject a second job; regression cancels a real detached test worker through a new Library instance. |
| P2 | Any live process at a saved PID was reported as a running worker. | Verify worker identity before reporting/signalling; an unrelated current-process PID is rejected without signalling it. |
| P2 | An older asynchronous scene load could overwrite a newly selected scene, or repopulate an unfinished capture. | Abort superseded loads and check generation tokens in both viewer and GUI. Three JavaScript regressions cover late success, clearing a pending scene and late errors. |
| P2 | A submitted paid job was not cancelled when subsequent response-URL validation failed. URLs could also refer to a different request. | Validate/store its cancellation URL first, bind response URLs to the returned request ID and run validation within cancellation handling. Mocked regressions confirm cancellation without visiting the rejected URL. |
| P2 | Retrying an interrupted ingest could move a new image directory inside the old directory. | Replace partial images explicitly and publish the manifest last; regression verifies no nested directory or leftover partial image. |
| P2 | Worker startup or a closed credential pipe could drop the HTTP response or leave a failed child running. | Return a clear sanitised error, mark startup failure and terminate a child that cannot receive credentials; regressions cover both paths and secret absence. |

Malformed artifact ports now also produce a sanitised provider error. Session keys stay
out of argv, files, API responses and browser storage; artifact downloads carry no key.

## Remaining limits

No real fal key or paid inference was used. Real provider access, latency, billing and
actual provider-output compatibility still need a user-triggered live submission. API
submission is deliberately not retried automatically after an ambiguous network failure.
Cancellation is best effort and can occur after provider processing/billing has started.

The existing four-photo local reconstruction/CUDA run and its measurements are recorded in
`example-report.json`; it was not retrained solely for this audit. Training-view PSNR is
not a held-out quality score. Both local and generated results have arbitrary scale.
ArUco metric alignment, arm removal, collision geometry and dynamic reconstruction remain
unimplemented. Existing simulator brief gaps remain in `simulation/BRIEF-CHECK.md`;
this appearance viewer does not close those gaps. The earlier user-requested lime arm
colour remains in the simulator.

Unrelated in-progress SAM prompt/UI changes elsewhere in the repository are excluded
from this commit.
